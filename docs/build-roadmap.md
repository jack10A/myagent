# Build Roadmap

## Phase 1: Foundation

- Monorepo scaffold.
- FastAPI backend.
- Next.js frontend.
- Docker Compose.
- Auth and profile.
- Core database models.

## Phase 2: MVP Intelligence

- Adaptive onboarding.
- Situation detector.
- Guardian review.
- Recommendation cards.
- Approval workflow.

## Phase 3: Real Connectors

- Google OAuth.
- Gmail read/draft scopes.
- Google Calendar read/write scopes.
- Weather provider.
- Emergency alert provider.

## Phase 4: Memory Upgrade

- Qdrant vector search.
- Entity extraction.
- Memory confidence and retention policy.
- User-editable memory.

## Phase 5: Production

- Alembic migrations.
- Background sync workers.
- Observability.
- Rate limiting.
- Audit logs.
- Billing.
